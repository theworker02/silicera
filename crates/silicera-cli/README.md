# silicera-cli

[![crates.io](https://img.shields.io/crates/v/silicera-cli.svg)](https://crates.io/crates/silicera-cli)
[![docs.rs](https://img.shields.io/docsrs/silicera-cli)](https://docs.rs/silicera-cli)

The `silicera` binary — operator surface for discovery, training, verification, measurement, research packs, and exports.

```bash
cargo install silicera-cli
silicera about
silicera commands
silicera guide quickstart
silicera report -o out/host-report.md
```

Grouped commands: `machine` · `hnep` · `measure` · `research` · `export` · `meta`. Flat aliases cover high-traffic verbs (`inspect`, `train`, `verify`, `doctor`, `report`, `toolchain`, `health`, …).
