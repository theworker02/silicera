AMD Zen focus

Support model

Exclusivity is enforced by architecture knowledge packs and topology validation — not a vendor-string check alone. Unsupported CPUs get a clear message and exit code 2.

  • docs/amd/overview.md
  • docs/amd/topology.md
  • docs/amd/support.md
  • profiles/amd/*.toml — public / measured facts only

Adding a pack

To document a new SKU class: add or extend TOML under profiles/amd/ with honest families, model_ranges, and cache bounds; validate with silicera probe. Do not claim coverage without validation.
